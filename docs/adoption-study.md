# Integration study kit

Run five observed integrations before publishing adoption or productivity claims.
Use different codebases and, where possible, developers who did not build Activity.

## Record for every session

| Metric | Definition |
|---|---|
| Time to first event | From reading the install command until one real business operation appears in the panel |
| Time to durable storage | Until the same event survives a process restart |
| Host code changed | Files and non-generated lines required outside the starter |
| Blocking moments | Every point where documentation, API or error output did not suggest the next action |
| Production intent | Yes, no or conditional, with the reason in the participant's words |

Test at least one memory evaluation, Next.js/PostgreSQL integration, non-Next HTTP
integration, custom UI using headless primitives and SQLite/local-first integration.

Create an [onboarding report](https://github.com/andreyshedko/activity/issues/new?template=onboarding.yml)
after each session. Case studies may only name a participant or company after they
approve the final wording, measured result and use of their logo.
